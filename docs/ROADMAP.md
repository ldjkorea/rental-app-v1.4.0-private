# v1.4.0 후속 개발 기준

## 유지할 결정

- 전기 2·3층 고정 공급가와 4층 잔액, 수도 층별 1명, 엘리베이터·오물비 원 단위 보존을 유지합니다.
- 월세는 `payday`, 관리비·공과금은 월말이며 다음 날부터 체납입니다.
- 계산은 `assets/billing.js`, 검증·저장은 `assets/core.js`에 모읍니다.
- 원본에 없는 과거 값은 확인 필요 상태로 표시하고, 운영 원본을 추정값으로 확정하지 않습니다.
- 고지서가 남은 세입자는 보관하며 체납·과거 기록을 유지합니다.

## 이번에 완료

기존 감사 변경 보존, 원자적 로컬 저장·다른 창 충돌 방지의 회귀, 과거 snapshot·납부 상태 일치 검증, 초안 복원과 저장 실패 대응, 고아 고지서 완납, 정책 우회 없는 Windows 실행기, 실제 PWA 업데이트·오프라인 검증, 전체 검사 실행 명령과 최종 증거 정리.

## 후속 우선순위

| 우선순위 | 작업 | 완료 조건 |
|---|---|---|
| 1 | Google Apps Script 원본 확보 및 서버 검증 | 인증·권한·revision 원자 비교·동시 저장·requestId 중복 처리·영구 저장 확인 |
| 2 | 실제 운영 JSON 이관 대조 | 월별 고지서 금액·납부일·체납 합계와 원본 자료 일치 |
| 3 | 운영 사이트 및 실제 기기 검증 | HTTPS 배포, 기존 설치형 앱 업데이트, 휴대폰 오프라인, 인쇄 결과 확인 |
| 4 | 부분 입금·여러 차례 입금 | 금액별 원장 모델과 기존 도장 데이터 마이그레이션을 먼저 설계 |
| 5 | 계약 변경 적용일·장기 이력 | 기존 snapshot 유지와 과거 자료 대조를 전제로 별도 설계 |
| 6 | CI 자동 검증 | 환경에 Playwright·Edge/Chromium을 명시하고 `npm run test:all` 실행 |

이 문서의 후속 항목은 완료된 기능으로 간주하지 않습니다. 자동 배포·예약 개발 작업은 등록하지 않았습니다.
