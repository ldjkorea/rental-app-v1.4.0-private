## 실패·실행 거부 처리

1. 이전 백업 가져오기 실패는 파일 입력 이벤트가 편집 버전을 올리던 문제였습니다. 마지막 작업에서 수정돼 있었고 이번에 다시 통과했습니다.
2. 기본 명령·파일·화면 도구는 Windows 샌드박스의 `apply deny-read ACLs` 초기화 오류가 발생했습니다. 보안 설정을 변경하지 않고 허용된 범위의 명령으로 파일 작업과 격리 테스트를 수행했습니다.
3. PowerShell의 `.ps1` 실행 거부를 확인했습니다. `실행.cmd`에서 실행 정책 우회를 제거하고 기존 Node.js 실행기를 직접 호출하도록 변경했습니다. 정상 서버 재사용과 타 프로젝트 서버 거부를 실제 배치 진입점으로 검증했습니다.
4. 새 회귀 테스트의 월별 고지서 참조와 초기 빈 문서의 샘플 주입 오류는 시험 코드에서 수정했습니다. 앱에서 발생하는 스크립트 오류 검사는 유지합니다.
5. 위 과정에서 재현된 앱 오류는 수정 후 전체 검사를 재실행했습니다. 최종 실패·건너뜀은 없습니다.
